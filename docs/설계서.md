# **차세대 AI-Native CRM 헬프데스크 시스템 최종 엔지니어링 설계서**

## **1\. 아키텍처 개요 및 핵심 설계 원칙**

본 시스템은 전통적인 헬프데스크(Zendesk, Chatwoot)의 옴니채널 수명주기 관리와 AI 에이전트 인지 루프를 유기적으로 결합한 **차세대 대화형 AI CRM**이다. 사후 대량 마케팅 캠페인 대신 고객과의 실시간 대화 자체를 살아있는 데이터 레코드로 전환하여, 개별 고객 맞춤 대응과 자율적인 백엔드 액션을 실행한다.

### **1.1 핵심 설계 원칙**

> * **EDA & Service-Mesh-less MSA**: 서비스 간 직접적인 HTTP/gRPC 호출을 배제하고, NATS를 단일 메시지/이벤트 백본으로 삼아 비동기 이벤트, 작업 큐, 동기 질의(Request-Reply)를 일원화한다.  
> * **Write 경로 격리 (Zero DB Direct Write)**: 외부 채널 어댑터, 웹 게이트웨이, AI 에이전트는 DB에 직접 쓰지 않고 NATS로 이벤트를 발행한다. DB 쓰기는 전용 적재 서비스(svc-ingestion-worker)가 배치로 일괄 처리한다.  
> * **단일 스토리지 내 하이브리드 온톨로지**: 관계형 헬프데스크 스키마, pgvector 기반 시맨틱 검색, 고객 중심 1\~2홉 온톨로지(Ego-Graph)를 단일 PostgreSQL 인스턴스에서 ACID 트랜잭션으로 보장한다.  
> * **채널별 장애 격리 (Blast Radius Control)**: 옴니채널 게이트웨이를 모놀리식으로 구성하지 않고 채널별 독립 컨테이너로 분리하여 특정 채널의 장애가 전체 상담 채널로 전파되는 것을 차단한다.

## **3\. NATS JetStream 메시징 및 토픽(Subject) 설계**

### **3.1 스트림 생성 및 보존 정책**

`# 1. 대화 이벤트 스트림 (불변 로그 90일 디스크 보존, Replay 지원)`  
`nats stream add CONVERSATIONS_STREAM \`  
  `--subjects "helpdesk.events.*.*.*.*" \`  
  `--storage file \`  
  `--retention limits \`  
  `--max-age 90d \`  
  `--replicas 3 \`  
  `--discard old`

`# 2. 비동기 분산 작업 큐 (컨슈머 처리 완료 시 즉시 삭제)`  
`nats stream add TASKS_STREAM \`  
  `--subjects "helpdesk.tasks.>" \`  
  `--storage file \`  
  `--retention workqueue \`  
  `--replicas 3`

## **4\. 데이터베이스 DDL 스키마 (PostgreSQL 16+)**

`CREATE EXTENSION IF NOT EXISTS "uuid-ossp";`  
`CREATE EXTENSION IF NOT EXISTS "vector";`

`-- 1. 테넌트 계정 마스터`  
`CREATE TABLE accounts (`  
    `id SERIAL PRIMARY KEY,`  
    `name VARCHAR(255) NOT NULL,`  
    `locale VARCHAR(10) DEFAULT 'ko',`  
    `created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL`  
`);`

`-- 2. 상담원 및 관리자`  
`CREATE TABLE users (`  
    `id SERIAL PRIMARY KEY,`  
    `email VARCHAR(255) UNIQUE NOT NULL,`  
    `name VARCHAR(255) NOT NULL,`  
    `role VARCHAR(50) DEFAULT 'agent' NOT NULL, -- 'administrator', 'agent'`  
    `availability_status VARCHAR(50) DEFAULT 'offline' NOT NULL, -- 'online', 'offline', 'busy'`  
    `created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL`  
`);`

`-- 3. 채널 수신함 (Inboxes)`  
`CREATE TABLE inboxes (`  
    `id SERIAL PRIMARY KEY,`  
    `account_id INT NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,`  
    `name VARCHAR(255) NOT NULL,`  
    `channel_type VARCHAR(50) NOT NULL, -- 'web', 'kakao', 'email', 'social'`  
    `enable_auto_assignment BOOLEAN DEFAULT TRUE NOT NULL,`  
    `created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL`  
`);`

`-- 4. 통합 고객 마스터 (Contact)`  
`CREATE TABLE contacts (`  
    `id SERIAL PRIMARY KEY,`  
    `account_id INT NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,`  
    `name VARCHAR(255),`  
    `email VARCHAR(255),`  
    `phone_number VARCHAR(50),`  
    `custom_attributes JSONB DEFAULT '{}'::jsonb,`  
    `created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL,`  
    `CONSTRAINT uq_contact_email UNIQUE (account_id, email)`  
`);`

`-- 5. 채널별 소스 식별자 매핑`  
`CREATE TABLE contact_inboxes (`  
    `id SERIAL PRIMARY KEY,`  
    `contact_id INT NOT NULL REFERENCES contacts(id) ON DELETE CASCADE,`  
    `inbox_id INT NOT NULL REFERENCES inboxes(id) ON DELETE CASCADE,`  
    `source_id VARCHAR(255) NOT NULL, -- 웹 쿠키 해시, 카카오 유저 해시, 이메일 주소 등`  
    `created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL,`  
    `CONSTRAINT uq_inbox_source UNIQUE (inbox_id, source_id)`  
`);`

`-- 6. 대화 / 티켓 (Conversation)`  
`CREATE TABLE conversations (`  
    `id SERIAL PRIMARY KEY,`  
    `account_id INT NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,`  
    `inbox_id INT NOT NULL REFERENCES inboxes(id) ON DELETE CASCADE,`  
    `contact_id INT NOT NULL REFERENCES contacts(id) ON DELETE CASCADE,`  
    `contact_inbox_id INT NOT NULL REFERENCES contact_inboxes(id) ON DELETE CASCADE,`  
    `assignee_id INT REFERENCES users(id) ON DELETE SET NULL,`  
    `status VARCHAR(50) DEFAULT 'open' NOT NULL, -- 'open', 'resolved', 'pending', 'snoozed'`  
    `priority VARCHAR(50) DEFAULT 'medium' NOT NULL, -- 'low', 'medium', 'high', 'urgent'`  
    `first_reply_created_at TIMESTAMP WITH TIME ZONE,`  
    `resolved_at TIMESTAMP WITH TIME ZONE,`  
    `custom_attributes JSONB DEFAULT '{}'::jsonb,`  
    `created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL,`  
    `updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL`  
`);`

`-- 7. 대화 메시지`  
`CREATE TABLE messages (`  
    `id SERIAL PRIMARY KEY,`  
    `account_id INT NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,`  
    `conversation_id INT NOT NULL REFERENCES conversations(id) ON DELETE CASCADE,`  
    `message_type INT NOT NULL, -- 0: incoming, 1: outgoing, 2: activity, 3: template`  
    `content TEXT,`  
    `private BOOLEAN DEFAULT FALSE NOT NULL, -- 내부 메모 여부`  
    `source_id VARCHAR(255), -- 이메일 Message-ID 또는 외부 메시지 식별자`  
    `sender_type VARCHAR(50) NOT NULL, -- 'User', 'Contact', 'AgentBot'`  
    `sender_id INT NOT NULL,`  
    `created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL`  
`);`

`-- 8. 온톨로지 노드 (엔티티)`  
`CREATE TABLE ontology_nodes (`  
    `id UUID PRIMARY KEY DEFAULT gen_random_uuid(),`  
    `account_id INT NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,`  
    `entity_type VARCHAR(50) NOT NULL, -- 'Customer', 'Product', 'PainPoint', 'Preference', 'Feature'`  
    `name VARCHAR(255) NOT NULL,`  
    `external_ref_id VARCHAR(255), -- contacts.id 또는 제품 식별자 연동`  
    `properties JSONB DEFAULT '{}'::jsonb,`  
    `embedding vector(1536), -- 시맨틱 유사도 검색용`  
    `created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL,`  
    `updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL`  
`);`

`-- 9. 온톨로지 엣지 (관계)`  
`CREATE TABLE ontology_edges (`  
    `id UUID PRIMARY KEY DEFAULT gen_random_uuid(),`  
    `account_id INT NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,`  
    `source_node_id UUID NOT NULL REFERENCES ontology_nodes(id) ON DELETE CASCADE,`  
    `target_node_id UUID NOT NULL REFERENCES ontology_nodes(id) ON DELETE CASCADE,`  
    `relation_type VARCHAR(100) NOT NULL, -- 'PREFERS', 'EXPERIENCED', 'CAUSED_BY', 'RESOLVED_BY'`  
    `weight FLOAT DEFAULT 1.0,`  
    `properties JSONB DEFAULT '{}'::jsonb,`  
    `created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL,`  
    `CONSTRAINT uq_edge UNIQUE (account_id, source_node_id, target_node_id, relation_type)`  
`);`

`-- 10. AI 도구 호출 및 액션 실행 감사 로그`  
`CREATE TABLE agent_tool_executions (`  
    `id SERIAL PRIMARY KEY,`  
    `account_id INT NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,`  
    `conversation_id INT NOT NULL REFERENCES conversations(id) ON DELETE CASCADE,`  
    `tool_name VARCHAR(100) NOT NULL,`  
    `input_args JSONB NOT NULL,`  
    `output_result JSONB NOT NULL,`  
    `is_success BOOLEAN NOT NULL,`  
    `requires_approval BOOLEAN DEFAULT FALSE,`  
    `approved_by INT REFERENCES users(id),`  
    `created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP NOT NULL`  
`);`

`-- 성능 인덱스`  
`CREATE INDEX idx_conversations_lookup ON conversations(account_id, status);`  
`CREATE INDEX idx_conversations_assignee_open ON conversations(assignee_id) WHERE status = 'open';`  
`CREATE INDEX idx_messages_conv_seq ON messages(conversation_id, created_at ASC);`  
`CREATE INDEX idx_contact_inboxes_lookup ON contact_inboxes(inbox_id, source_id);`  
`CREATE INDEX idx_ontology_nodes_ref ON ontology_nodes(account_id, entity_type, external_ref_id);`  
`CREATE INDEX idx_ontology_edges_traversal ON ontology_edges(account_id, source_node_id, relation_type);`

### **5.1 데이터 적재 서비스 (svc-ingestion-worker)**

> * **역할**: NATS helpdesk.events.\> 스트림을 구독하여 PostgreSQL에 배치(Batch)로 영속화하는 단일 쓰기 전담 서비스.  
> * **배치 정책**: 500건 누적 또는 100ms 타임아웃 중 먼저 도달하는 시점에 플러시(Flush).  
> * **멱등성 보장**: ON CONFLICT (id) DO NOTHING 및 source\_id 중복 방지 제약으로 NATS 재전송 시 중복 생성 차단.

### **5.2 옴니채널 어댑터 마이크로서비스群**

> * **gateway-web**: 브라우저 SDK와의 WebSocket 연결 풀 유지, NATS Core Pub/Sub과 브라우저 간의 실시간 브리지.  
> * **gateway-kakao**: 카카오 알림톡/상담톡 대행사 웹훅을 수신해 공통 메시지 포맷으로 정규화 후 NATS 발행. 아웃바운드 시 24시간 세션 규칙 검증 및 알림톡 템플릿 전환.  
> * **gateway-email**: SMTP/MIME 파싱 전담. In-Reply-To, References 헤더를 파싱하여 기존 대화 스레드로 매핑하고 본문 서명/구분자 정리.

### **5.3 비즈니스 코어 및 운영 서비스**

> * **svc-core**: 대화 상태 전이(Open ↔ Pending ↔ Resolved) 유한 상태 머신(FSM) 제어 및 동기성 REST/NATS Request-Reply 응답 제공.  
> * **svc-sla-routing**: 가용 상담원 탐색, 동시 처리 용량(C\_{\\text{current}} \< C\_{\\max}) 기반 라운드로빈 배정, 영업 시간 기반 SLA 만료 타이머 감시.

### **5.4 AI Agent Brain (svc-ai-agent)**

> * **Ego-Graph Context Assembly**: 고객 식별 시 PostgreSQL에서 1\~2홉 온톨로지(선호 속성, 과거 불만 요인, 관련 기능 결함)를 단일 쿼리(\< 3ms)로 추출하여 프롬프트에 주입.  
> * **자율 작업 및 원클릭 승인 카드 분기**:  
  * 저위험 액션(배송 조회, 상태 안내): API 호출 후 결과 답변 즉시 전송.  
  * 고위험 액션(환불, 구독 변경): agent\_tool\_executions에 기록 후 상담원 화면에 \[승인 및 실행\] 버튼을 포함한 인터랙티브 카드로 라우팅.  
> * **비동기 온톨로지 진화 (Graph Evolution Worker)**: 대화 종결 이벤트 수신 시 대화 전문을 비동기로 분석하여 신규 발견된 속성(Node) 및 관계(Edge)를 DB에 반영.

## **7\. 프론트엔드 작업 공간 (3-Pane Split View)**

상담원 SPA 대시보드는 gateway-web과 단일 WebSocket 세션을 맺고 NATS Core 이벤트를 실시간으로 동기화한다.

> * **좌측 패널 (Left Pane: 대화 큐 및 필터)**:  
  * NATS helpdesk.realtime.\<acc\>.\> 이벤트를 구독하여 페이지 새로고침 없이 티켓 카드 재정렬, 읽지 않은 뱃지 카운트, SLA 마감 타이머 실시간 갱신.  
> * **중앙 패널 (Center Pane: 메시지 스레드 & 에디터)**:  
  * 대화 히스토리 및 상대방 타이핑 인디케이터 실시간 노출.  
  * AI가 도구 실행 승인을 요청한 경우, 일반 텍스트가 아닌 \[환불 승인하기\] 버튼이 포함된 인터랙티브 액션 카드를 렌더링.  
> * **우측 패널 (Right Pane: AI Living Profile & 온톨로지)**:  
  * 단순 고객 인적사항을 넘어 ontology\_nodes와 ontology\_edges에서 실시간 로드된 **"고객 맞춤 성향 요약"**, **"과거 발생했던 주요 마찰(PainPoint) 이력"**, "실시간 이탈 위험도(Churn Score)"를 시각화.

## **8\. 단계별 구현 로드맵**

`Phase 1: 데이터 및 메시징 백본 구축`  
 `├── 1. PostgreSQL 16+ 스키마 및 인덱스 배포 (Core DDL + pgvector + 온톨로지 테이블)`  
 `├── 2. NATS JetStream 클러스터 구성 및 스트림 정의 (CONVERSATIONS_STREAM, TASKS_STREAM)`  
 `└── 3. svc-ingestion-worker 구축 (NATS 이벤트 ➔ PG 100ms 마이크로배치 적재)`

`Phase 2: 옴니채널 어댑터 및 코어 엔진 개발`  
 `├── 1. gateway-web (WebSocket 양방향 브리지 및 위젯 SDK postMessage 격리 통신)`  
 `├── 2. gateway-kakao (알림톡/상담톡 웹훅 수신 및 24시간 세션 제어 어댑터)`  
 `├── 3. gateway-email (MIME 파싱 및 In-Reply-To 헤더 기반 스레딩 엔진)`  
 `└── 4. svc-core & svc-sla-routing (FSM 상태 머신, 상담원 Capacity 배정)`

`Phase 3: AI 에이전트 인지 계층 및 온톨로지 파이프라인 결합`  
 `├── 1. Ego-Graph 1~2홉 탐색 쿼리 모듈 및 RAG 결합 파이프라인 구현`  
 `├── 2. ReAct 추론 엔진 및 Tool Calling 실행/원클릭 승인 카드 연동`  
 `└── 3. 대화 완료 기반 비동기 온톨로지 추출 워커 (Graph Evolution) 가동`

`Phase 4: 프론트엔드 워크스페이스 및 운영 고도화`  
 `├── 1. 상담원 3단 분할 뷰(3-Pane Split View) SPA 완성 및 NATS WebSocket 실시간 연동`  
 `├── 2. 비즈니스 통계 대시보드 및 CSAT 피드백 분석 리포트 구현`  
 `└── 3. 채널 어댑터별 Rate Limiting 및 서킷 브레이커 안정화`
